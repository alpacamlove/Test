# Комикс по истории из SillyTavern

Здесь история из SillyTavern превращается в анимированный комикс: сцены с силуэтами, светом и погодой, реплики в облачках, звук. Всё рисуется кодом (SVG, Canvas, Web Audio), без внешних картинок, и открывается в браузере телефона.

## Что уже есть

- `demo/comic.html` — демо стиля «Таверна на краю ночи»: 6 сцен, 13 кадров. Страница опубликована как артефакт Claude, в ней есть кнопка «Загрузить историю».

## Как прислать историю

1. В SillyTavern открой чат, нажми ☰ слева от поля ввода и выбери **Manage chat files**.
2. У нужного чата нажми кнопку экспорта: лучше `.jsonl` (в нём все сообщения), подойдёт и `.txt`.
3. Загрузи файл кнопкой «Загрузить историю» в демо. Можно и сюда, в папку `story/`, через GitHub («Add file» → «Upload files»).
4. Если хочешь, добавь карточки персонажей (`.png` или `.json`): по ним видно, как выглядят герои.

## Как это устроено

Страница — один HTML-файл без сборки. Внутри:

- **сцены** — функции, которые рисуют слои SVG (фон, середина, персонажи, передний план), с параллаксом при движении камеры;
- **персонажи** — силуэты с контровым светом и светящимися глазами (эмоции задаются формой глаз);
- **частицы** — дождь, искры, пыль и магия на Canvas;
- **сюжет** — массив `SHOTS`: у каждого кадра есть подпись или реплика, движение камеры и действие (молния, открыть дверь, зажечь свечу).
